# Sutra build plan

## Folders
- `app/`: `(auth)/login`, `(portal)/{aicte,institution,university,verifier,student}`, later `verify/[recordId]`, `transparency`, `docs`, `portal-demo`, `privacy`, `api/v1/*`
- `components/`: `ui/` (shadcn), `layout/` (portal shell, logo, pipeline), later `DataTable`, `KpiCard`, `StatusBadge`, `FilterBar`, `ExportMenu`
- `lib/`: `supabase/` (browser, server, admin, middleware), `crypto/`, `audit/`, `credentials/`, `adapters/`, `auth/`, `validation/`, `ask/`, `ratelimit.ts`, `mask.ts`, `nav.ts`, `demo-accounts.ts`
- `supabase/migrations/`: ordered SQL
- `scripts/`: `keys`, `migrate`, `seed`, `setup`, `verify-seed`, later `rls-test`, `smoke`
- `demo-files/`: generated by seed; `tests/`: vitest

## Migrations
1. `0001_enums.sql`: enums, canonical JSON, timestamp helpers
2. `0002_tables.sql`: all Section 4 tables + indexes + `updated_at` triggers
3. `0003_audit.sql`: `audit_log`, `append_audit()`, append-only triggers, demo tamper/restore, anchors
4. `0004_rls.sql`: helper functions, grants, deny-by-default policies
5. `0005_views.sql`: dashboard views (security_invoker), seat matrix check
6. `0006_realtime.sql`: publication

## Routes (final)
Public: `/`, `/login`, `/verify`, `/verify/[recordId]`, `/transparency`, `/privacy`, `/docs`, `/docs/rules`, `/portal-demo`, `/.well-known/aicte-public-key.json`
AICTE: `/aicte`, `alerts`, `institutions`, `quota`, `fraud`, `duplicates`, `ask`, `reports`, `approvals`, `audit`, `rules`
Institution: `/institution`, `upload`, `students`, `issues`, `history`, `reports`, `integration`
University: `/university`, `results`, `certificates`
Verifier: `/verifier`, `requests`; Student: `/student`, `consents`, `scholarships`, `marksheet`
Shared: `/settings/security`
API: `/api/v1/{students,students/validate,students/[apaarId]/verify,programs/[id]/intake-status,credentials/[recordId],certificate-line/[studentId],scholarship/verify,university/results,public-key,openapi.json}`

## Build order
Sections 13.1 to 13.10; typecheck + lint + commit after each phase.
1. Foundation: scaffold, theme, Supabase clients, migrations, crypto + tests, audit chain + tests, keys, auth, login, shells
2. Seed: deterministic seeder, planted scenarios, credentials, audit chain, demo files, verify counts
3. Validation + upload wizard
4. Dashboards + alerts + webhooks
5. Verification + credentials + student portal
6. Audit + security pages
7. Marks + scholarship
8. Reports + APIs
9. AI features + fraud page
10. Polish + README + DEMO + smoke
